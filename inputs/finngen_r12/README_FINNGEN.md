## How the corrected run was made (4 Nov 2026; preserved and validated; not re-executed on 16 Nov 2026)
1. **Pre-specification.** The rerun was pre-specified and hash-frozen before any outcome was read (`RERUN_PRESPECIFICATION.md`, `FROZEN_PRESPEC_HASH.txt`).
2. **Coordinate conversion.** FinnGen R12 summary statistics (GRCh38) were converted to GRCh37 with the UCSC hg38ToHg19 chain through a custom Python mapping (`10_lift.py`; the liftOver binary was not used). 99.99% of uniquely matched rsIDs agree with the 1000 Genomes EUR BIM (`LIFTOVER_QC.tsv`, `11_bim_qc.py`).
3. **Annotation.** MAGMA annotation used window 0,0 and NCBI37.3 (`12_annotate.sh`; `ANNOTATION_QC.tsv`). The sentinel checks passed 120/120 (`SENTINEL_CHECKS.tsv`, `13_sentinels.py`).
4. **Gene analysis.** MAGMA gene analysis used the SNP-wise mean model, the 1000G EUR LD reference and N = 500,348 (`14_magma_gene.sh`; logs in `run_records_20261104/magma_logs/`).
5. **QA.** QA passed (`QA_REPORT.md`); deviations are in `DEVIATIONS.tsv`.

From these MAGMA outputs, `analysis/finngen/` (20 → 21_ledger → 100 → st11/133) reproduces every FinnGen number in the paper inside this repository.
